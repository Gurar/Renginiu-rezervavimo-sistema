# Event Reservation System
## 🌟 About

The project is designed for event management and participant registration. The system will allow organizers to create and administer events, and users to view and register for events.

## 🎯 Project features
- User registration and login
- Event creation and management
- Event reservation system
# 🧰 Technologies Used
## Backend
- Java 21
- Spring Boot
- Hibernate / JPA
## Frontend
- React
